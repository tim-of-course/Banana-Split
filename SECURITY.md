# Security Policy

## Supported version

Security fixes are applied to the current V1 release on the `main` branch.

## Reporting a vulnerability

Please do not report vulnerabilities in a public issue. Use GitHub's private
vulnerability reporting for this repository from the **Security** tab, then
select **Report a vulnerability**.

Include the affected version or commit, reproduction steps, impact, and any
suggested mitigation. Sensitive reports and workflow data should remain in the
private report.
