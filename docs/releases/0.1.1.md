# Banana Split 0.1.1 — Cherry Accent identity

Internal alpha, intended for supervised use on Windows 11 x64 and macOS on Apple Silicon or Intel.

## Changes

- Adds the selected Cherry Accent banana symbol to the plugin listing, composer, and bundled skill.
- Uses a compact square SVG in the composer and a square PNG for the listing, with matching dark-theme metadata.
- Includes the editable brand source, transparent logos, monochrome variants, and icons under `assets/branding/cherry-accent/`.

This patch updates presentation and version metadata. Workflow behavior, configuration, and durable-state formats are unchanged.

## Install or update

Download the archive matching your platform and extract it, including hidden files. Follow the [quickstart](../../README.md#quickstart) for installation or the [update procedure](../OPERATIONS.md#changing-configuration-and-updating) for an existing installation. Codex uses an installed copy, so pulling the repository alone does not refresh the icon in that copy.

Release files:

- `banana-split-0.1.1-windows-x64.tar.gz`
- `banana-split-0.1.1-darwin-arm64.tar.gz`
- `banana-split-0.1.1-darwin-x64.tar.gz`
- `SHA256SUMS`

## Verification scope

Verified on Linux with Node 24 and Bun 1.3.14: source checking; 117 passing tests with 3 platform-specific skips; cross-compilation for all three targets; archive contents, icon paths, executable permissions, and SHA-256 checksums. Codex CLI 0.160.0 installed the package and its App Server resolved the plugin and skill icon metadata. The existing disabled setting was preserved.

Live agent workflows and Codex Desktop rendering on Windows and macOS are not verified for this release. Linux and WSL remain unsupported runtime platforms. Packages are unsigned; macOS packages are not notarized.
